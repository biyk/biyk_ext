Portions of arent/battlecast.py port tactical decision heuristics (expected-hit-damage
targeting, focus-fire/finish priority, threat-aware position scoring) from:

  battlecast-engine — https://github.com/bjedrzejewski/battlecast-engine
  Copyright (c) 2026 Bartosz Jedrzejewski
  Licensed under the MIT License (full text below).

Only the algorithm idea was ported to Python and rewritten against THIS project's own
simulation primitives (planner.*, arent.observe). No SRD game data, monster stat blocks,
spell lists or other content files from battlecast-engine were copied into this project:
all runtime data comes from our own /plan payload. The SRD 5.2 CC-BY-4.0 attribution that
battlecast-engine carries for its data files therefore does not apply to this port, and no
data files were reproduced here.
